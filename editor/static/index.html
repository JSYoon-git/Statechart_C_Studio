    Draw a statechart
    1. Pick the ▭ state tool and drag on the canvas to make a box. Type a name and press Enter
    2. Point at the first state with a ●→ default transition
    3. Drag a → transition from state to state and write its guard (e.g. button == true, cnt >= 50u)
    4. Generate C shows the code, Build compiles it
    There are no events — guards read input variables. New here? Open New ▾ → LED blink first
