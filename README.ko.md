# Statechart C Studio

**브라우저에서 스테이트차트를 그리면, 10 ms 태스크에 바로 넣는 C 코드가 나오고, 그 자리에서 빌드까지 됩니다.**

임베디드 시스템을 배우는 사람을 위한 교육용 도구입니다.

**[브라우저에서 열기](https://jsyoon-git.github.io/Statechart_C_Studio/)** · [English README](README.md)

---

## 왜 만들었나

대학교에서는 C언어 수업과 객체지향 수업을 따로 들었습니다. 각각은 이해가 됐습니다.
그런데 이 둘이 실제 임베디드 시스템에서 어떻게 맞물려 돌아가는지는 아무도 보여 주지 않았습니다.
화이트보드에 그린 상태 머신이 어떻게 마이크로컨트롤러에서 도는 C 코드가 되는지, 누가 누구를 부르는지, 얼마나 자주 부르는지를요.

현업에 나가서야 알게 됐습니다. 현업의 그림은 단순하고, 놀랄 만큼 일관됩니다.

- 주기 태스크(여기서는 10 ms)가 각 모듈의 `Main` 함수를 부릅니다.
- 모듈은 데이터를 구조체에 담고, 상태 머신처럼 동작합니다.
- 입력은 인자로 들어오고, 출력은 반환값으로 나갑니다.
- 시간은 마법이 아닙니다. 변수로 셉니다. (`cnt++` 하다가 `cnt >= 50`이면 500 ms)

학생 때 이걸 봤으면 좋았겠다고 생각했습니다. 그래서 제가 그때 갖고 싶었던 도구를 만들었습니다.
스테이트차트를 그리면 거기서 나오는 C 코드를 보여 주고, 컴파일까지 해서 진짜로 돌아가는 코드임을 확인할 수 있습니다.
뒤에 오는 후배들이 한 번 써 보면 좋겠습니다.

## 할 수 있는 것

1. 페이지를 엽니다. **LED blink** 예제가 이미 열려 있습니다.
2. **Generate C**를 누르고 코드를 읽어 보세요. 상태나 전이를 누르면 해당하는 코드 줄이 표시됩니다.
3. **Build**를 누르세요. 브라우저 안에서 엄격한 C89 컴파일러로 컴파일합니다. 설치도 서버도 필요 없습니다.
4. 그림을 고치면 버튼이 다시 파란색이 됩니다. 초록색이 될 때까지 다시 생성하고 빌드해 보세요.
5. **New ▾**에서 다음 예제를 열어 보세요. 초급부터 고급까지 있습니다(아래 표).
6. **주석**(✎ 도구)으로 내 그림을 설명해 두세요. **Save**는 작업 내용을 내 컴퓨터에 파일로 저장합니다.

생성되는 코드는 `X.c`, `X.h` 두 파일입니다. MCU 프로젝트에 복사해서, 이미 돌고 있는 10 ms 태스크에서 두 함수만 부르면 됩니다.

```c
static Led itsLed;
static bool io_Led_led = false;

/* 10 ms task */
void Task_10ms(void) {
    io_Led_led = Led_Main(&itsLed);      /* 입력 읽기 -> 내부 반응 -> 전이 최대 1개 -> 출력 */
}

int main(void) {
    Led_Init(&itsLed);                   /* 한 번: 변수 초기화 + 처음 상태로 진입 */
    for (;;) {
        Task_10ms();                     /* every 10 ms */
    }
}
```

프레임워크가 없습니다. 이벤트 큐도, 타이머도, 매크로도 없습니다. 전이에는 **[Guard]**만 있고, 그림에 쓴 C 코드가 그대로 들어갑니다.
"이벤트"는 Guard가 읽는 입력 변수일 뿐입니다. 생성 코드는 C89(ANSI C)라서 오래되고 작은 MCU 컴파일러에서도 빌드됩니다.

## 예제

모든 예제에는 핵심 개념을 설명하는 주석이 영어와 한국어로 들어 있습니다(언어 버튼으로 바뀝니다).

| 단계 | 예제 | 배우는 것 |
|---|---|---|
| 초급 | LED blink | 상태 둘, 변수로 시간 세기, 설정값 |
| 초급 | 버튼 램프 | Guard의 입력, 전이 action이 entry action보다 먼저 |
| 초급 | 3색 신호등 | 상태 셋의 순환, 카운터 하나를 함께 쓰기 |
| 중급 | 자판기 | 값을 가진 입력, 조건 커넥터(if / else) |
| 중급 | 세탁기 | 복합 상태, 히스토리, 부모의 카운터 |
| 중급 | 버튼 디바운스 | MCU 디바운스의 정석 패턴 |
| 고급 | 교통 신호등 | AND(병렬) 상태, 히스토리 |
| 고급 | 모터 제어 | 두 모듈을 출력→입력으로 연결 |
| 고급 | 모뎀 재연결 | 정션, 종료, 재시도 횟수 제한 |

## 선생님과 학생을 위해

교실과 독학 모두를 생각하고 만들었습니다. 이렇게 써 볼 수 있습니다.

- LED blink로 시작하세요. "언제 바뀌는 걸까? 시간은 어디에 있지?"라고 물어보고, `blinkTicks`를 바꿔 보게 합니다.
- 학생이 직접 기계(문, 세탁 과정, 자판기)를 그리고, 나온 C 코드에서 각 상태를 찾아보게 합니다.
- 일부러 망가뜨려 봅니다(기본 전이 빼기, 잘못된 Guard). Problems 탭을 읽어 봅니다.
- 같은 동작을 다르게 그린 두 그림을 비교하고, 어느 쪽 코드가 읽기 쉬운지 이야기해 봅니다.

## 어떻게 동작하나

- 편집기는 순수 HTML, CSS, JavaScript입니다. 빌드 과정이 없습니다.
- 코드 생성기는 Python입니다. 브라우저에서는 [Pyodide](https://pyodide.org/)(WebAssembly로 컴파일한 Python)로 돌려서,
  페이지가 정적 파일뿐이라 GitHub Pages에서 동작합니다.
- **Build**는 WebAssembly로 만든 clang([binji/wasm-clang](https://github.com/binji/wasm-clang))을 씁니다.
  옵션은 `-std=c89 -pedantic -Wall -Wextra -Wdeclaration-after-statement`입니다.
- 처음 접속하면 약 40 MB(Pyodide와 컴파일러)를 받습니다. 그 뒤에는 브라우저가 보관합니다.
- 그림은 내 브라우저(로컬 저장소)에 저장됩니다. 서버로 보내지 않습니다.
- 폰에서도 됩니다. 왼쪽 패널은 서랍이고, 코드 보기는 전체 화면이며, 두 손가락으로 확대합니다.

Python 서버로 내 컴퓨터에서 돌리려면(MSVC나 gcc로도 컴파일할 수 있습니다):

```bash
python editor/server.py
```

그리고 http://127.0.0.1:8770/ 을 엽니다. 자세한 내용은 [editor/README.md](editor/README.md)에 있습니다.
